# Security Policy

## Supported Versions

specrails-web is the official website and documentation frontend for the SpecRails project. It is a hosted service and does not have versioned releases.

| Component | Supported |
|-----------|-----------|
| specrails-web (latest deployment) | ✅ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's [private security advisory feature](https://github.com/fjpulidop/specrails-web/security/advisories/new) to report vulnerabilities confidentially.

Include in your report:
- A clear description of the vulnerability and its potential impact
- Steps to reproduce the issue (URL, browser, steps)
- Any relevant screenshots or proof of concept

## Response Timeline

| Step | SLA |
|------|-----|
| Initial acknowledgment | 48 hours |
| Triage and severity assessment | 7 days |
| Resolution timeline communicated | 14 days |
| Fix deployed (critical) | As soon as practicable |

## Responsible Disclosure Policy

We ask that you:
- Give us reasonable time to investigate and remediate before public disclosure
- Avoid accessing or modifying data that does not belong to you
- Avoid disrupting the service for other users

In return, we commit to:
- Acknowledging your report promptly
- Keeping you informed of our progress
- Crediting you in the security advisory (unless you prefer anonymity)

## Scope

This policy covers the specrails-web frontend application. It does not cover third-party services linked from the site or the specrails-desktop backend.

For vulnerabilities in specrails-desktop, please see [specrails-desktop's security policy](https://github.com/fjpulidop/specrails-desktop/blob/main/SECURITY.md).
