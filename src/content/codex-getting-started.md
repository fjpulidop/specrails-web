specrails is designed to be CLI-agnostic — when Codex support ships, you will be able to run the full agent pipeline with **OpenAI Codex** just as easily as with Claude Code. Both CLIs will be first-class citizens.

---

## Prerequisites

| Requirement | Version | Notes |
|-------------|---------|-------|
| **Node.js** | 18+ | [nodejs.org](https://nodejs.org) |
| **Git** | any | Your project must be a git repo |
| **OpenAI Codex CLI** | latest | Install with `npm install -g @openai/codex` |
| **OpenAI API key** | — | Set `OPENAI_API_KEY` in your environment |

---

## Step 1 — Install specrails

From your project directory:

```bash
npx specrails-core@latest init --root-dir .
```

The installer is identical for both CLIs. You will see:

```
✅ Templates installed
✅ Commands installed
🚀 Ready! Run /specrails:enrich in Claude Code or Codex
```

---

## Step 2 — Configure with the TUI installer (Codex)

Open Codex in your project directory and run `/specrails:enrich`:

```bash
cd <your-project>
codex
> /specrails:enrich
```

The TUI installer analyzes your codebase, lets you select agents and models, and configures your team. It works the same way as in Claude Code — same `--quick` shortcut, same `--from-config` mode for non-interactive setups.

---

## Step 3 — Run your first task

```
> /specrails:implement "add a health check endpoint"
```

The full pipeline runs: Architect → Developer → Security Reviewer → Reviewer → PR.

## FAQ

**Can I switch between Claude Code and Codex on the same installation?**

Yes. specrails installs into `.claude/` — a directory it creates in your project root. The name comes from historical convention; it is not tied to the Claude Code binary. You can run `/specrails:enrich` or any `/specrails:*` command from either CLI at any time.

---

**What is different between the two CLIs?**

The specrails agent pipeline and features are identical. The only difference is which CLI binary you type at the terminal (`claude` vs `codex`) and which API key you need (`ANTHROPIC_API_KEY` vs `OPENAI_API_KEY`). Everything inside specrails — agents, specs, memory, commands — stays the same.

---

**Do I need to run `/specrails:enrich` again if I switch CLIs?**

No. The configuration generated by `/specrails:enrich` is CLI-agnostic. Run it once with whichever CLI you prefer; the result works with both.

---

**Will the agents use the same model?**

No. Agents use the model of the CLI running them. Claude Code agents use Claude models; Codex agents use OpenAI models. The specrails agent prompts are model-agnostic and work well with both.

---

**Are there any features that require Claude Code specifically?**

Not in the core specrails workflow. If you use Paperclip (the multi-agent orchestration layer), you can configure agents to run on either CLI independently.

---

**How do I run diagnostics with Codex?**

```bash
npx specrails-core doctor
```

The `doctor` command is a standalone CLI tool — it runs independently of your AI CLI and works for both Claude Code and Codex installations.
