# Ajusta modelos sin perder el contrato

Ajustar modelos debe mejorar una fase conocida sin reducir la spec ni las obligaciones de verificación.

## Haz un cambio acotado

Abre los ajustes del proveedor, rail o rol que quieras modificar. Usa identificadores y niveles compatibles. Si la interfaz no ofrece una capacidad, añadir un nombre parecido al prompt no la habilita.

Comprueba a qué afecta el ajuste: conversación, paso de ejecución o perfil de roles. Guárdalo y revisa su efecto en la siguiente ejecución.

## Contrasta calidad y consumo

Compara el diff, la verificación y los reintentos. Mantén una revisión suficiente para código desconocido o contratos entre repositorios. La información de costes varía: un consumo no disponible no equivale a cero.

Una actualización de runtime puede cambiar las capacidades. Resuelve los errores de configuración antes de usar nuevos ajustes en un proyecto de producción.
