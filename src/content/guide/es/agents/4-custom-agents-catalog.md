# Añade agentes personalizados concretos

Los agentes personalizados reúnen un rol o unas instrucciones reutilizables. Asígnales una responsabilidad concreta y una salida clara.

## Define el rol

Describe qué entradas puede inspeccionar, qué debe hacer y qué evidencias debe devolver. Separa los hechos del proyecto de las instrucciones y vincula las referencias al repositorio correcto.

Usa el catálogo y la configuración compatibles. La instalación e invocación varían entre proveedores: un archivo Markdown no demuestra por sí solo que se haya utilizado el rol.

## Prueba un traspaso útil

Ensáyalo en una tarea acotada. Por ejemplo, un revisor de contratos puede comparar una API con su cliente y señalar incompatibilidades concretas. No debe completar una spec basándose sólo en un resumen.

Usa [loops personalizados](/docs/pipeline-the-loop-builder) para conectar el rol con comprobaciones y condiciones explícitas.
