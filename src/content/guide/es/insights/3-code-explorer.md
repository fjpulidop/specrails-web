# Explora los archivos y sus evidencias

Archivos es un explorador y una vista de observabilidad. Sirve para comprender el código y los cambios registrados, no para editarlo.

## Empieza por el repositorio correcto

Selecciona repositorio, busca una ruta y abre el archivo. La misma ruta en otro repositorio es otra referencia. Añade los archivos útiles a la misión para aportar contexto explícito.

Lee el código junto a su explicación. Los resúmenes describen propósito, responsabilidades y relaciones visibles; el modelo, la fecha y la vigencia permiten valorarlos. Regenera una explicación desactualizada cuando cambie el código.

## Sigue el trabajo registrado

La historia de construcción y la procedencia conectan el archivo con jobs y diffs disponibles. Un diff registrado muestra la evidencia de ese job, no necesariamente todos los cambios del archivo. La ausencia de historial no equivale a un error de carga.

El código truncado o la falta de evidencias limitan la explicación. Comprueba el código real y sus relaciones antes de aceptar una inferencia. Usa el [detalle de ejecución](/docs/pipeline-the-job-detail-view) para el contexto de implementación y verificación.
