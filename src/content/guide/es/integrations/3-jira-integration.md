# Mantén Jira vinculado al proyecto

La integración con Jira vincula incidencias externas al flujo compartido del proyecto. La selección de repositorios indica dónde cambiar código; no redefine quién gestiona Jira.

## Configura la relación

Usa los ajustes del plugin para conectar el sitio y el proyecto previstos. Confirma la autenticación y revisa identificadores, títulos y descripciones importados antes de ejecutar.

Decide qué se mantiene en Jira y qué detalles se refinan en Specrails. No crees copias independientes de una incidencia sólo para apuntar a otro repositorio.

## Revisa las actualizaciones

Comprueba la clave antes de escribir en Jira. El estado local y el flujo de Jira son sistemas distintos: terminar una ejecución no demuestra que una transición remota haya funcionado.

Si falla la sincronización, inspecciona el error y reconcilia la incidencia antes de repetir. Añadir otra carpeta conserva el backlog y la integración del proyecto lógico.
