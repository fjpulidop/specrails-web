# Specrails kennenlernen

Specrails ist ein lokaler Arbeitsbereich, der eine Softwareidee in eine präzise Spec, eine koordinierte Umsetzung und ein prüfbares Ergebnis überführt. Beginnen Sie mit einer Mission; im Board verwalten Sie denselben Backlog direkt.

## Ihr erster Ablauf

Installieren Sie die App und melden Sie sich bei einem Anbieter an. Fügen Sie das Projekt und seine Repositories hinzu, öffnen Sie eine Mission und beschreiben Sie das Ziel. Prüfen Sie die Spec, wählen Sie einen Loop und bewerten Sie die Nachweise vor jeder Übernahme.

Eine Mission kann auch Code untersuchen, den Browser bedienen und Prozesse beobachten. Die Spec beschreibt die Änderung, der Loop den Ablauf. Claude, Codex, Gemini und Kimi unterstützen unterschiedliche Funktionen. Anbieter und Integrationen können Kontext übertragen und Kosten verursachen.

## Was wo läuft

Specrails ist eine einzige App. Desktop enthält seine Engine, **Specrails Core**: Wenn Sie ein Projekt hinzufügen, bereitet Desktop mit Core die Workflow-Dateien vor, die Ihr Anbieter benötigt, und die integrierten Loops Implement und Batch Implement nutzen Core, um die Änderung zu planen, umzusetzen, zu prüfen und zu reviewen, bevor das Ergebnis an Desktop zurückgeht. Desktop übernimmt alles andere: Missionen, Board, Worktrees, Commits, Pull Requests und Verlauf.

## Core ist in Desktop integriert

Core ist kein eigenständiges Produkt. Sie installieren es nicht, starten es nicht im Terminal und fügen es nicht zu Ihren Repositories hinzu. Desktop enthält eine getestete Version; unter **Desktop-Einstellungen → Updates → Specrails Core** sehen Sie die verwendete Version und wenden Core-Updates auf alle Projekte an.

Diese Anleitung beschreibt den aktuellen Produktstand. Prüfen Sie Ihre Version, wenn ein Steuerelement fehlt.
