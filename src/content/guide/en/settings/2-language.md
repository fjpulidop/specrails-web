# Choose the interface language

Specrails and this website provide interface translations for English, Spanish, French, German, Portuguese, Italian, Chinese and Japanese.

## Separate language from project content

Changing the interface does not translate source code, existing specs or provider output automatically. State the desired response language when it matters to the mission, and keep technical identifiers unchanged.

Generated file explanations record their language and generation metadata. Regenerate an explanation when you need it in another language rather than assuming an old cached response changed with the interface.

## Read current documentation

The guide uses current translated articles where available. Otherwise it explicitly opens the current English article, while keeping navigation in your selected language. This avoids presenting an older translation as instructions for today's product.

English and Spanish cover the complete current guide; the other languages include the essential introductory, first-mission and delivery journeys.
