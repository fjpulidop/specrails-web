# Choose a comfortable theme

Use the appearance controls to choose the application's available theme. Theme changes should improve reading without changing project or execution state.

## Check the whole workspace

Inspect conversation text, code, diffs and status indicators in the selected theme. Do not rely on color alone to interpret execution: read the status, icon or accessible label as well.

Browser content can use its own website theme, so changing Specrails does not necessarily restyle the page you are testing. A screenshot records the visible page state at capture time.

The website has its own theme and language controls, independent from the desktop application's preferences.
