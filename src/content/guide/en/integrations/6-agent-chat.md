# Use the mission conversation

The mission conversation is the primary place to work with Specrails. It combines project context, references, tools and delivery decisions while Board remains available for direct organization.

## Begin with intent

Describe the outcome and constraints. Ask for investigation when the implementation is not yet clear, and review a spec before launching substantial work. Use `@` for relevant context and `#` for a spec or other recorded reference; spec results take priority in the picker.

References belong where you insert them in the message. Check the selected repository when adding files with similar paths.

## Keep control while work runs

Sending during a turn queues a follow-up by default. Promote a pending message with Steer when it should reach the active agent without stopping it, or edit and delete messages that are still pending. Stop is a separate action.

Start with [your first mission](/docs/missions-first-mission), then read [receipts and steering](/docs/missions-steering-and-receipts) and [delivery actions](/docs/missions-review-and-delivery).
