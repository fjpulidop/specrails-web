# Flow：まず作り、spec はあとで

**新機能。** Flow を使うと、何を作りたいかまだはっきりしていない段階から、エージェントと一緒に動くコードを作れます。ミッションの会話でエージェントと話すと、エージェントが分離された worktree で実際のコードを書いて実行します。最初に spec を用意する必要はありません。結果に納得したら **これで決まり** と伝えると、レールが spec を導出し、いつもどおりに作業をデリバリーします。

## 見つけるなら Flow、任せるなら Implement

ルール、受け入れ基準、API やデータモデルなど、変更をすでに説明できる場合は [Implement](/docs/pipeline-rails-and-jobs) を使います。spec を合意してからレールに任せます。

探索的・視覚的なものや、本格的に取り組む前に試してみたいアイデアなど、形がまだはっきりしない場合は Flow を使います。一緒に作りながら結果を見つけ、spec は作ったものをもとに書かれます。

## ミッションから Flow を始める

Flow を名前で頼む必要はありません。探索的なこと（「…を試してみたい」「どんな見た目がいいか分からない」）を伝えると、ミッションに 2 つの道を示すカードが表示されます。今すぐ一緒に作る **Flow** と、まず spec を合意する **Spec + Implement** です。カードはおすすめの道に印を付け、その理由を一文で説明します。もう一方の道も常にワンクリックで選べ、そちらを選んだり **今はしない** を押したりしても、エージェントがしつこく勧めることはありません。

Flow を選ぶと確認が表示されます。Specrails はエージェントがコードを書ける分離された worktree を作成し、メインブランチには触れません。**Flow を開始** を押してください。ボードに **Flow 中** ラベル付きの仮 spec が表示されます。クリックするとミッションに戻れます。

## 作っている間も主導権はあなたに

会話の見た目が変わり、入力欄の上に Flow バーが表示されます。worktree のブランチ、追加・削除行数付きの変更ファイル、そしてプロバイダーの請求額に基づく Flow の実費（推定値は表示しません）が表示されます。

- **変更を表示** は、変更された各ファイルの状態と +/− を一覧表示します。
- **一時停止** はエージェントを止め、worktree と spec を保持します。ミッションには **Flow を再開** が表示され、アプリを再起動した後も再開できます。
- **破棄** は確認のうえ、worktree、そのブランチ、仮 spec を削除します。
- **いつでも割り込み**：エージェントが作業中でも入力でき、メッセージは現在のステップに割り込みます。送信ボタンが稲妻に変わり、エージェントはすぐに新しい情報で作業を続けます。

Flow は自分の worktree の中にだけ書き込みます。Flow の外では、ミッションは読み取り専用のままです。1 つのミッションで同時に開ける Flow は 1 つです。

## 「これで決まり」と伝える

結果に満足したら **これで決まり** を押します。Flow バーが消え、いつものレール起動カードが **Flow → Spec** ループを選択済み・空いているレールを選択済みの状態で表示されます。必要ならエンジン、モデル、エフォートを調整して **起動** を押してください。レビュー上限や予算に達している場合、カードはその旨を表示し、起動しません。**まだ** を押すと Flow に戻ります。

Flow → Spec ループは、作ったものから Specrails の spec と OpenSpec の change を導出し、検証とレビューを行い、change をアーカイブして、通常の実行と同じようにデリバリーします。デリバリーカードはミッションに表示され、[レビューパケット](/docs/missions-review-and-delivery) では導出された spec が変更のどの部分を説明しているかを確認できます。

## Jira はデリバリー時だけ

Flow の最中や破棄したときに、Jira には何も送られません。[Jira](/docs/integrations-jira-integration) に接続されたプロジェクトでは、デリバリーがレビューに達した時点で初めて課題が作成されます。課題は導出された spec を含む完成した状態で作成され、レビューに対応するステータスへ直接移ります。

## 必要条件

Flow は、Flow を導入する Specrails Desktop のリリースから利用できます。また、Desktop に内蔵された Specrails Core が Flow に対応している必要があります。**Flow を開始** が無効な場合は、不足しているものがカードに表示されます。**Desktop 設定 → 更新 → Specrails Core** から Specrails Core を更新してください。Flow のコストは Analytics で独立したサーフェス **Flow** として表示されます。
