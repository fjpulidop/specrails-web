# Specrails を知る

Specrails は、ソフトウェアのアイデアを明確なスペック、連携した実装、レビュー可能な成果物へ進めるローカルの作業環境です。まずミッションから始めましょう。Board では同じバックログを直接管理できます。

## 最初の流れ

アプリをインストールしてプロバイダーに認証します。プロジェクトとリポジトリを追加し、ミッションで期待する結果を伝えます。スペックを確認してループを選び、各成果物を受け入れる前に検証結果を確認します。

## どこで何が動くか

Specrails はひとつのアプリです。Desktop にはエンジンである **Specrails Core** が同梱されています。プロジェクトを追加すると、Desktop は Core を使ってプロバイダーが必要とするワークフローファイルを準備します。組み込みの Implement ループは Core を使って変更の計画、開発、検証、レビューを行い、結果を Desktop に返します。ミッション、Board、worktree、コミット、プルリクエスト、履歴など、それ以外はすべて Desktop が担います。

## Core は Desktop に内蔵されています

Core は単独の製品ではありません。インストールしたり、ターミナルから実行したり、リポジトリに追加したりする必要はありません。Desktop にはテスト済みのバージョンが含まれており、**Desktop 設定 → 更新 → Specrails Core** で使用中のバージョンを確認し、Core の更新をすべてのプロジェクトに適用できます。

このガイドは現在の製品を説明しています。操作が見つからない場合はインストール済みのバージョンを確認してください。
