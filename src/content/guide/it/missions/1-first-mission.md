# Avvia la prima missione

Scegli il progetto e apri una missione. Descrivi risultato, vincoli e un modo concreto per verificarne il successo.

## Fornisci il contesto corretto

Aggiungi file con `@` e una spec con `#`. Il selettore dà priorità alle spec e mantiene il riferimento nel punto di inserimento. Controlla il repository: percorsi uguali possono indicare file diversi.

Chiedi un’esplorazione se la soluzione non è chiara; l’agente può anche intervistarti e mostrare un [Intent](/docs/missions-intent-mode). Rivedi bozza e criteri prima di avviare Implement o un loop che hai aggiunto. Leggere un altro repository non lo include automaticamente nell’ambito di implementazione.

## Segui il lavoro

Durante un turno, Invia mette il messaggio in coda per il turno successivo. Guidare consegna esplicitamente un messaggio in attesa all’agente attivo senza fermarlo. La consegna dipende dal provider; Interrompi resta un’azione separata. Due spunte verdi richiedono evidenza di lettura, non una semplice risposta del modello.

[Rivedi la consegna](/docs/missions-review-and-delivery).
