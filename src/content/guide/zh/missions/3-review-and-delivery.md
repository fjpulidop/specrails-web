# 审核并接受交付

实现会产生需要检查的代码变化和验证证据。已有测试通过，并不证明所要求的功能已经完成。

## 区分操作

本地集成会将工作应用到已核实的集成分支。检出会把工作分支移到仓库的本地目录，并不等于接受规格。创建 PR 前请检查仓库、目标分支和差异。worktree 是隔离的 Git 工作目录，不是 GitHub 托管的工作空间。

## 保留部分成果

涉及多个仓库时，需要审核每个交付，包括明确标记为无变化的结果。集成不是跨仓库的原子事务：某个操作失败时，已接受的结果仍会保留。

出现冲突或基线变化时，保留本地修改、阅读错误，并只重试尚未完成的操作。不要为了隐藏卡片而删除 worktree。修订会保留冻结的范围及上一次交付的上下文。
